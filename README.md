# FPV技术空间

一个专注于FPV技术、三维建模和3D打印的现代化个人展示网站，可以在任何设备上完美显示。

## 功能特性

- 📱 **响应式设计** - 自动适应手机、平板和电脑屏幕
- 🚀 **快速加载** - 优化的代码确保快速访问
- 🎨 **科技感设计** - 使用深色主题和现代UI设计
- 📞 **移动端友好** - 完美支持手机访问

## 预览

网站已经部署到 GitHub Pages，可以通过以下链接访问：
[点击访问我的个人网站](https://yourusername.github.io/personal-website)

> 注意：你需要将 `yourusername` 替换为你的实际 GitHub 用户名。

## 本地运行

1. 克隆仓库：
```bash
git clone https://github.com/yourusername/fpv-tech-space.git
```

2. 进入项目目录：
```bash
cd fpv-tech-space
```

3. 在浏览器中打开 `index.html` 文件

## 自定义内容

你可以通过编辑 `index.html` 文件来自定义网站内容：

- 修改FPV技术相关内容
- 添加建模项目展示
- 更新3D打印作品
- 自定义技能展示
- 添加联系方式

## 核心领域

- **FPV技术** - 第一人称视角飞行技术
- **三维建模** - CAD设计和结构优化
- **3D打印** - 快速原型和定制零件制造
