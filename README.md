# 我的个人网站

这是一个简单而现代的响应式个人网站，可以在任何设备上完美显示。

## 功能特性

- 📱 **响应式设计** - 自动适应手机、平板和电脑屏幕
- 🚀 **快速加载** - 优化的代码确保快速访问
- 🎨 **现代设计** - 使用渐变色彩和现代UI设计
- 📞 **移动端友好** - 完美支持手机访问

## 预览

网站已经部署到 GitHub Pages，可以通过以下链接访问：
[点击访问我的个人网站](https://yourusername.github.io/personal-website)

> 注意：你需要将 `yourusername` 替换为你的实际 GitHub 用户名。

## 本地运行

1. 克隆仓库：
```bash
git clone https://github.com/yourusername/personal-website.git
```

2. 进入项目目录：
```bash
cd personal-website
```

3. 在浏览器中打开 `index.html` 文件

## 自定义内容

你可以通过编辑 `index.html` 文件来自定义网站内容：

- 修改标题和描述
- 添加个人信息
- 展示作品集
- 联系信息
- 社交媒体链接

## 技术栈

- HTML5
- CSS3 (包含响应式设计)
- 原生JavaScript (可选)
